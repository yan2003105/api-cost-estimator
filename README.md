# OpenAI API Cost Estimator

Unofficial tool, not affiliated with OpenAI. A single-file local calculator: enter input/output tokens and prices per 1M tokens yourself, get an estimated cost. Prices are not fetched automatically, because official prices change. No login, no API key, no upload.
